# Kimyo mock — Milliy sertifikat, 3-variant

Premium kimyo 3-kitob (Boymurodov · Ergashev, "Kelajak mediklari"), 2-modul,
3-variant — kitobning 207–210-betlari. 43 topshiriq, 180 daqiqa.

## Sayt

`index.html` — bitta mustaqil fayl. Server ham, kutubxona ham kerak emas.
GitHub Pages yoqilgach havola: `https://<hisob>.github.io/kimyo-mock/`

## Qismlar

| Topshiriq | Turi | Tekshirish |
|---|---|---|
| 1–32 | Yopiq test (A–D) | avtomatik |
| 33–35 | Umumiy shartli test (A–F) | avtomatik |
| 36–40 | Ochiq javobli | avtomatik |
| 41–43 | Yozma ish (25 balldan) | yakuniy javob avtomatik, oraliq qadamlar mezon bo‘yicha qo‘lda |

## O‘qituvchi paneli

Havola oxiriga `#ustoz` qo‘shiladi:
`https://<hisob>.github.io/kimyo-mock/#ustoz`

Panelda natija kodlari qabul qilinadi, yozma ish mezon katakchalari bilan
baholanadi, jadval Excelga nusxalanadi. Jurnal shu brauzerda saqlanadi.

## Ball taqsimoti

Kitobda 1–40-testlarning ball qiymati ko‘rsatilmagan. Sukut bo‘yicha har biri
1 ball (40) + yozma ish 75 = **115 ball**. Baho chegaralari: A+ 86 %, A 76 %,
B+ 66 %, B 56 %, C+ 46 %. Ikkalasi ham panelning «Baholash sozlamalari»
bo‘limidan o‘zgartiriladi.
